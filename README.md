## 👨‍💻 About Me

I'm an **AWS Certified Solutions Architect** and Cloud Engineer with 3+ years building scalable, high-availability systems on AWS. I specialize in serverless architectures, microservices, Infrastructure as Code, and AI-powered automation.

Currently working remotely for a California-based company, designing cloud-native solutions and internal automation pipelines. Previously built backend and cloud services for a Dominican Government platform with **500K+ downloads**.

Things I care about most:

- ☁️ **Cloud Architecture** — Designing serverless, event-driven, and distributed systems on AWS aligned with the Well-Architected Framework
- 🔧 **Infrastructure as Code** — Provisioning reproducible, version-controlled environments with Terraform, CloudFormation & AWS CDK
- 📦 **Container Orchestration** — Kubernetes and Docker for scalable, self-healing deployments
- 🔍 **Observability & Reliability** — CloudWatch, SLOs, automated alerting, and incident response
- 🤖 **AI Automation** — Integrating LLMs and AWS ML services (Rekognition) into production workflows
- 🔐 **Cloud Security** — IAM least-privilege, VPC isolation, and security-first architecture
